# C++ Data Structures and Algorithms

## About the Project

This repository contains C++ programs based on Data Structures and Algorithms (DSA). It includes implementations of stacks, queues, linked lists, searching, hashing, and other programming concepts.

## Programs Included

1. **Queue Using Array (`Queue_using_array.cpp`)**
   - Implementation of a queue using an array.

2. **Queue Using Linked List (`queue_linklist.cpp`)**
   - Implementation of a queue using a linked list.

3. **Stack Using Array (`stack_array.cpp`)**
   - Implementation of a stack using an array.

4. **Stack Using Linked List (`stack_linklist.cpp`)**
   - Implementation of a stack using a linked list.

5. **Doubly Linked List (`double_linklist.cpp`)**
   - Implementation of doubly linked list operations.

6. **Music Playlist (`music_playlist.cpp`)**
   - Music playlist management using a linked list.

7. **Binary Search (`binary_search.cpp`)**
   - Implementation of the binary search algorithm.

8. **Hashing (`hash.cpp`)**
   - Implementation of hashing concepts.

9. **Postfix (`postfix.cpp`)**
   - Operations on postfix expressions.

10. **Complex Numbers (`complex.cpp`)**
    - Operations involving complex numbers.

## Technologies Used

- Programming Language: C++
- IDE: Visual Studio Code
- Compiler: GCC
- Platform: GitHub

## How to Run the Programs

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required `.cpp` file.
4. Compile the program:

   ```bash
   g++ filename.cpp -o output
   ```

5. Run the program:

   ```bash
   ./output
   ```

   On Windows PowerShell, use:

   ```powershell
   .\output.exe
   ```
